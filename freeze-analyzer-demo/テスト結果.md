- [x] UTF-8（BOM付き）・経過秒の形式も読める（時刻の列が「経過時間(秒)」）
- [x] 温度の列がないCSVは、理由を表示して読み飛ばす
- [x] 評価する温度の列を自動選択（列名に「中心」）。違う名前でも画面で選び直せる
- [x] 過冷却で−5℃を一度下回っても、通過時間を正しく計算（T04）
- [x] 外れ値を除外して計算し、詳細グラフに×印で表示（T05）
- [x] 基準値（帯・目標・合格ライン）を画面で変えると全体が再計算される
- [x] 表をコピーしてExcelに貼り付けられる（タブ区切り）
