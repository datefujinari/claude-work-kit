# 手順書：冷凍試験 解析ツール（Cowork 版デモ）

受け取った PC でこのデモを開く・見せる・直すための手順です。
本体は **`冷凍試験解析ツール_デモ.html` の1ファイルだけ**。グラフ部品・計算・ダミーデータをすべて中に入れてあるので、インストール不要、ネット接続なしでも動きます。

---

## 1. 受け取る

どちらか一方で OK。

- **ZIP**: GitHub のキットのページ → 緑の「Code」→「Download ZIP」→ 展開 → `freeze-analyzer-demo` フォルダ
- **git**: `git clone https://github.com/datefujinari/claude-work-kit.git`（取得済みなら `git pull`）

> 見せるだけなら `冷凍試験解析ツール_デモ.html` を1つ持っていけば足ります（メール添付・USB でも可）。ドラッグ&ドロップの実演をするなら `dummy` フォルダも一緒に。

---

## 2. 開いて動きを確かめる（2分）

1. `冷凍試験解析ツール_デモ.html` をダブルクリック（Chrome か Edge で開く）
2. 開いた時点でダミーデータ（鶏もも肉200g・条件違いの6試験）が表示される
3. 次が表示されれば OK
   - 上部の集計（試験 6 件・合格 4・要確認 0・不合格 2・外れ値 4点を除外）
   - 冷却曲線の重ね合わせ
   - 指標の比較表と、通過時間のランキング

---

## 3. 打ち合わせでの見せ方（約10分）

| 順番 | 操作 | 伝えること |
|---|---|---|
| 1 | 「すべて消す」→ `dummy` フォルダの CSV 6本をまとめて画面にドラッグ&ドロップ | 1ファイルずつ開かなくても、まとめて読み込める |
| 2 | 冷却曲線の重ね合わせ。凡例をクリックして出し入れ、ドラッグで拡大、ダブルクリックで戻る | 条件（設定温度・風速）の違いがひと目でわかる |
| 3 | 指標の比較表と合否の色分け | 通過時間・到達時間・冷却速度・過冷却を自動で計算・判定 |
| 4 | 通過時間のランキング | どの条件が良いかすぐわかる |
| 5 | 表で T05 をクリック → 詳細 | センサーの外れ値を自動で除き、×印で示す |
| 6 | 上部の基準（帯・目標温度・合格ライン）を変える | その場で全部が再計算される |
| 7 | 「表をコピー」→ Excel に貼り付け | 今の Excel 作業にもつなげられる |
| 8 | お客様の CSV をドラッグ&ドロップ | 実データでも動く（下の 4 を参照） |

> 「サンプルに戻す」でいつでもダミーデータの表示に戻せます。

---

## 4. お客様の CSV を読み込むとき

1. 「すべて消す」→ CSV を画面のどこかにドラッグ&ドロップ（または「CSVを追加」）
2. 「評価する温度」が品温の中心になっているか確認。違えばプルダウンで選び直す
3. 基準（最大氷結晶生成帯・目標温度・合格ライン）をお客様の基準に合わせる

**読めないとき**は、その場で直そうとせずに次をメモして持ち帰る:
- ロガーの機種名、CSV の先頭10行くらいの形（列の並び・見出し・時刻の書き方）
- 今の Excel ツールで出している数字。こちらの結果と並べて比べる（ずれたら、どの時点を凍結開始としているかなど、計算方法の違いを聞く）

> [!IMPORTANT]
> データはこの PC の中だけで処理され、外部には送られません。
> **お客様の CSV をこのフォルダに保存したり、キットのリポジトリに push したりしないこと。**

## 5. 困ったとき

| 症状 | 対処 |
|---|---|
| 何も表示されない | HTML が途中までしかコピーされていない可能性（正しいサイズは約1.2MB）。取り直す |
| 「読み込めませんでした」と出る | 温度の列がない、または表の形が想定外。4 の「読めないとき」をメモして持ち帰る |
| 判定がおかしい | 「評価する温度」が品温（中心）になっているか、基準値が合っているか確認 |
| 表をコピーできない | ブラウザがクリップボードを許可していない。もう一度押すか、別のブラウザ（Chrome / Edge）で開く |
| 文字が少し違って見える | ネットにつながっていないと Web フォントが使えず、PC の標準フォントで表示される（動作には影響なし） |

## 6. 直す・機能を足すとき（Claude Code / Cowork）

使うだけなら不要です。HTML は `src/` のファイルから作っています。

| ファイル | 内容 |
|---|---|
| `src/template.html` | 画面（見た目と動き） |
| `src/analysis.js` | CSV の読み込みと指標の計算（ブラウザ・Node 共通） |
| `src/gen.py` | ダミーデータの生成と、Python で別に計算した期待値（`expected.json`）の作成 |
| `src/test.js` | JavaScript の計算結果を Python の期待値と照合するテスト |
| `src/build.py` | `template.html` に計算とダミーデータを埋め込み、HTML を作る |
| `テスト結果.md` | 作成時のテスト結果（49項目一致）と確認したこと |

必要なもの（改修するときだけ）: Python 3 と numpy（`pip install numpy`）、Node.js（LTS）。npm のパッケージは使いません。

```powershell
cd <キット>\freeze-analyzer-demo\src
python gen.py      # src\dummy\ にダミーCSVと expected.json を作る
node test.js       # 計算のテスト（「n/n 件 OK」になること）
python build.py    # src\dist\ に HTML ができる
```

> [!NOTE]
> - スクリプトはダミーデータを **`src\dummy\`** から読みます（キットでは表示用に1つ上の `dummy\` に置いています）。`gen.py` を先に流せば `src\dummy\` ができます。
> - `build.py` が作る HTML は、グラフ部品（Plotly.js）を**インターネット（CDN）から読み込みます**。オフラインでも動く完成版（今の `冷凍試験解析ツール_デモ.html`）は、Plotly.js basic v2.35.2（MIT ライセンス）を HTML の中に埋め込んだものです。オフライン用に作り直すときは Claude に「Plotly.js を埋め込んだ1ファイルの HTML にして」と頼んでください。

Claude Code に頼む例:

> このフォルダの 手順書.md と テスト結果.md を読んで構成を把握して。〇〇の形式のCSVが読めるように src を直し、テストを足して、HTML を作り直して。
