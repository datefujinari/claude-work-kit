# phone-drop

iPhone の Safari から、この PC に写真・動画を送るための小さな受信サーバー。iPhone にアプリは要らない。

## 使い方

1. `phone-drop.bat` をダブルクリック（PC のブラウザに QR コードが出る）
2. iPhone のカメラで QR を読み取る → Safari で開く
3. 「写真を選ぶ」→ 写真を選ぶと、そのまま PC に保存される
4. 10分間なにも送られてこなければ自動で終了する（すぐ止めるなら黒い画面で Ctrl+C）

保存先は既定で `ピクチャ\iPhone受信`。終了時に受け取ったものがあればフォルダが開く。

### オプション

```
python phone_drop.py --dir D:\写真 --minutes 5 --port 8765 --no-browser
```

- `--dir` 保存先 / `--minutes` 自動終了までの分数 / `--port` ポート番号
- `--no-browser` QR をブラウザではなく黒い画面に表示する

## 初回だけの準備

- `pip install --user segno`（QR コードの作成に使う）
- PC と iPhone を同じルーターにつなぐ
- 初回起動時に Windows のファイアウォールの確認が出たら「プライベート ネットワーク」だけにチェックして許可する
- PC 側のネットワークが「パブリック」だとつながらない。家のネットワークなら、設定 → ネットワークとインターネット → イーサネット（または Wi-Fi）→「プライベート ネットワーク」にする

## 安全のための仕組み

| 仕組み | 内容 |
|---|---|
| 使い捨てトークン | 起動ごとに推測できない合言葉を作って QR に入れる。合言葉のない通信は拒否する |
| LAN だけで待ち受け | PC の LAN の IP アドレスだけで待ち受ける。インターネットは使わない |
| 自動終了 | 一定時間なにもなければ終了する。必要なときだけ動く |
| 受け取る種類を制限 | jpg / jpeg / png / heic / heif / gif / webp / mov / mp4 / m4v だけ。1ファイル 4GB まで |
| ファイル名の無害化 | フォルダ名などは取り除き、保存先フォルダの外に書き込めないようにする。同名なら `(1)` を付ける |

**限界:** 通信は HTTP（暗号化なし）。家庭や職場の、知っている人だけが使うネットワーク向け。カフェなどの公共 Wi-Fi では使わない。
