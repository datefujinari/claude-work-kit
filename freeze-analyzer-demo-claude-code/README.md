# 冷凍試験 解析ツール（デモ）

温度ロガーのCSVを複数まとめて読み込み、冷却曲線の重ね合わせと指標の比較を表示するブラウザ用ツール。
インストールは不要で、`index.html` をブラウザで開くだけで動く。データはPCの外に送られない。

## 使い方
- `index.html` をダブルクリックで開き、CSVをドラッグ&ドロップする（複数可）
- 「サンプルで試す」でダミーデータ（6試験）を読み込める。`index.html?sample` で開くと最初から読み込んだ状態になる
- 基準（帯の上限・下限、目標温度、通過時間の基準）は画面上で変えられる。プリセットは「食品の冷凍（−18℃）」「低温試験（−40℃）」
- グラフ右上のカメラのアイコンで画像を保存、「指標の表をCSVで保存」で結果をExcelで開けるCSVにする

## 必要なもの
- Chrome / Edge などのブラウザ
- インターネット接続は不要（グラフ部品 Plotly.js basic v2.35.2〈MITライセンス〉を `vendor/` に同梱。`vendor/` が無いときだけ CDN から読む）

## 計算している指標（`analysis.js`）
| 指標 | 計算方法 |
|---|---|
| 帯に入る・抜ける時刻 | 品温が上限（−1℃）／下限（−5℃）を**最後に**下回った時刻（線形補間）。過冷却で一度下回っても誤判定しない |
| 通過時間 | 帯を抜けた時刻 − 帯に入った時刻。基準以下で「合格」 |
| 目標温度への到達 | 目標温度を最後に下回った時刻 |
| 平均冷却速度 | （開始温度 − 目標温度）÷ 到達時間 |
| 過冷却 | 0℃以下で下がりきった後に 0.5℃以上の急な上昇がある点。最低温度と深さ |
| 外れ値 | 前後の値の両方から15℃以上外れた点、−99.9 などのエラー値。計算から除き、詳細グラフに×で表示 |

評価する列は、列名に「中心」「品温」「CH1」などを含む列を自動で選ぶ（画面で変更できる）。

## 読めるCSV
- 文字コード: UTF-8 / Shift-JIS（自動判定）。区切り: カンマ・タブ・セミコロン
- 先頭の機器情報の行は読み飛ばす（「記録間隔,30秒」のような行は詳細に表示）
- 1列目が時刻: `2026/10/01 09:00:00` などの日時、`09:00:00` の時刻、経過時間の数値（見出しに「秒」「時間」があれば換算、なければ分）

## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` | 画面とスタイル |
| `app.js` | 読み込み・グラフ・表の動き |
| `analysis.js` | CSVの解析と指標の計算（画面に依存しない。Node でもテストできる） |
| `vendor/plotly-basic.min.js` | グラフ部品（Plotly.js、MITライセンス） |
| `samples.js` | 「サンプルで試す」用の埋め込みデータ（`tools/make_dummy.py` が生成） |
| `sample_data/` | ダミーCSV 6件（急速・標準・緩慢・過冷却・センサー異常・別書式） |
| `tools/make_dummy.py` | ダミーデータの生成: `python tools/make_dummy.py` |
| `tests/test_analysis.js` | 計算のテスト: `node tests/test_analysis.js` |
