# 手順書：冷凍試験 解析ツール（Claude Code 版デモ）

受け取った PC でこのデモを開く・見せる・直すための手順です。
**インストールは不要**で、ブラウザ（Chrome / Edge）があれば動きます。グラフ部品も同梱しているので、ネットにつながっていなくても動きます。

---

## 1. 受け取る

どちらか一方で OK。

- **ZIP**: GitHub のキットのページ → 緑の「Code」→「Download ZIP」→ 展開 → `freeze-analyzer-demo-claude-code` フォルダ
- **git**: `git clone https://github.com/datefujinari/claude-work-kit.git`（取得済みなら `git pull`）

> フォルダは**中身ごと**コピーしてください。`index.html` だけを別の場所に移すと、`app.js` などが見つからず動きません。

---

## 2. 開いて動きを確かめる（2分）

1. `index.html` をダブルクリック（Chrome か Edge で開く）
2. 「**サンプルで試す**」を押す → ダミーデータ6試験が読み込まれる
3. 次が表示されれば OK
   - 上部の数字（試験数 6・合格 4・不合格 2）
   - 冷却曲線の重ね合わせ／通過時間の棒グラフ
   - 指標の比較表（行をクリックすると下に詳細グラフ）

> 最初からサンプルを読み込んだ状態で開くには、アドレスバーの末尾に `?sample` を付けます（例: `…/index.html?sample`）。打ち合わせ前に開いておくと便利です。

---

## 3. 打ち合わせでの見せ方（約10分）

| 順番 | 操作 | 伝えること |
|---|---|---|
| 1 | 「サンプルで試す」 | CSVを1つずつ開かなくても、まとめて読み込める |
| 2 | 冷却曲線の重ね合わせ。凡例をクリックして試験を出し入れ、ドラッグで拡大 | 条件の違いがひと目でわかる（−1〜−5℃の帯・目標温度の線つき） |
| 3 | 通過時間の棒グラフ | どの条件が速いか、基準を満たすかがすぐわかる |
| 4 | 指標の比較表。見出しクリックで並べ替え | 通過時間・到達時間・冷却速度・過冷却を自動計算 |
| 5 | 表で「試験E」をクリック → 詳細グラフ | センサー異常（外れ値）を自動で除き、×印で示す |
| 6 | 基準のプリセットを「低温試験（−40℃）」に切り替え | 基準を変えると全部その場で再計算される |
| 7 | お客様のCSVを画面にドラッグ&ドロップ | 実データでも動く（下の 4 を参照） |

---

## 4. お客様の CSV を読み込むとき

1. 「すべてクリア」でサンプルを消す
2. CSV を画面にドラッグ&ドロップ（複数まとめて可）
3. 「評価する列」が正しいか確認。自動では列名に「中心」「品温」「CH1」を含む列を選ぶ。違えばプルダウンで選び直す
4. 基準（帯の上限・下限、目標温度、通過時間の基準）をお客様の基準に合わせる

**読めないとき**は、その場で直そうとせずに次をメモして持ち帰る:
- ロガーの機種名、CSV の先頭10行くらいの形（列の並び・見出し・時刻の書き方）
- 文字コード（メモ帳で開いて文字化けするか）、区切り文字
- 今の Excel ツールで出している数字（通過時間など）。こちらの結果と並べて比べる

> [!IMPORTANT]
> データはこの PC の中だけで処理され、外部には送られません。
> **お客様の CSV をこのフォルダに保存したり、キットのリポジトリに push したりしないこと。**

---

## 5. 結果を保存する

- **表**:「指標の表をCSVで保存」→ Excel でそのまま開ける CSV（BOM 付き UTF-8）
- **グラフ**: グラフにマウスを乗せると右上に出るカメラのアイコン → PNG で保存

---

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 画面は出るがグラフが出ない | `vendor` フォルダが一緒にコピーされているか確認（`vendor/plotly-basic.min.js`） |
| 何も表示されない・ボタンが効かない | フォルダごとコピーされているか確認（`app.js` `analysis.js` `samples.js` が同じ場所にあるか） |
| 「読み込めなかったファイル」と出る | 温度の表が見つからない形式。4 の「読めないとき」をメモして持ち帰る |
| 判定がおかしい | 「評価する列」が品温（中心）になっているか、基準値が合っているか確認 |
| 文字化けする | Shift-JIS / UTF-8 以外の文字コードの可能性。CSV をメモ帳で開き「名前を付けて保存」で UTF-8 にして読み直す |

---

## 7. 直す・機能を足すとき（Claude Code）

使うだけなら不要です。改修するときだけ、次を入れます。

- Node.js（LTS）… 計算のテスト用: `winget install OpenJS.NodeJS.LTS`
- Python 3 … ダミーデータの作り直し用（標準ライブラリのみ。追加のインストールは不要）
- npm は使いません

PowerShell でこのフォルダに移動して Claude Code を起動し、たとえば次のように頼みます。

```powershell
cd <キット>\freeze-analyzer-demo-claude-code
claude
```

> README.md を読んで構成を把握して。このCSV（列の並びは〇〇）が読めるように直して、テストを追加して。

改修したら必ずテストを流します。

```powershell
node tests\test_analysis.js        # 計算のテスト（すべて成功になること）
python tools\make_dummy.py         # ダミーデータを作り直すとき（sample_data と samples.js が更新される）
```

ファイルの役割や計算方法の詳細は `README.md` を参照。
