# タスク管理ガイド

> 要約: 思いついたら `00_Inbox/` に入れるだけ。Claude が振り分けてタスクノート（`05_Tasks/`）にし、[[タスクボード.base|タスクボード]] で進捗を一覧する。毎日「今日やる」は3つまで。

## 全体の流れ

```
思いつく → 00_Inbox に書く → Claudeに「Inbox整理して」
        → タスク / プロジェクト / ナレッジ に振り分け
        → タスクボードで状況を確認 → 進んだらClaudeに報告（または自分で status を変更）
```

## 1. Inbox に入れる（あなた）
- `00_Inbox/` にメモを置くだけ。書き方は自由
  - 1件ずつノートを作っても、`00_Inbox/Inbox.md` に箇条書きで足していってもOK
- 期限・相手・関連プロジェクトなどが分かれば一緒に書いておくと振り分けが正確になる
  - 例: `- 〇〇さんに見積もり依頼 10/10まで`
- 2分で終わることはメモせずにすぐやる

## 2. 振り分け（Claude）
「Inbox整理して」と頼むと、Claude が次の基準で振り分ける。

| Inboxの中身          | 行き先                                |
| ----------------- | ---------------------------------- |
| 1回の行動で終わる・やることが明確 | `05_Tasks/` にタスクノート                |
| 複数の手順があり、ゴールがある   | `10_Projects/<名前>/` にプロジェクト＋最初のタスク |
| やる必要はないが残したい知識    | `30_Knowledge/`                    |
| 記事・本などのメモ         | `40_Resources/`                    |
| 不要・重複             | `90_Archive/`（削除はしない）              |
| 判断できない            | Inboxに残し、Claude が質問する              |

振り分け後、Claude は「何をどこへ移したか」を報告し、`01_Daily/` の AIログに記録する。

## 3. タスクの状態（status）

| status | 意味 | ボード上の表示 |
|---|---|---|
| `todo` | 未着手（次にやる） | 進行中・未着手 |
| `doing` | 進行中 | 進行中・未着手 |
| `waiting` | 人の返事待ちなど、自分では進められない | 待ち |
| `someday` | いつかやる・期限なし | いつか |
| `done` | 完了 | 完了 |

その他のプロパティ:
- `today` … 今日やるなら `true`（**3つまで**）
- `priority` … `高` / `中` / `低`
- `due` … 期限（`YYYY-MM-DD`）
- `project` … 関係するプロジェクトへのリンク（例: `"[[10_Projects/〇〇/_index]]"`）

## 4. 進捗の管理
- **一覧で見る**: [[Home]] の埋め込みボード、または [[タスクボード.base|タスクボード]] を開く。ビューは「今日やる / 進行中・未着手 / 待ち / いつか / ボード / 完了 / すべて」
- **更新する**: 次のどちらでもOK
  - Claude に伝える: 「〇〇終わった」「〇〇は△△待ち」「〇〇を今日やる」など。Claude が status を変え、タスクノートの `## 進捗ログ` に記録する
  - 自分で変える: タスクノートのプロパティ欄で `status` / `today` を編集する
- サブタスクがあるときは、タスクノートの `## サブタスク` にチェックボックスで書く

## 5. 習慣
- **毎朝5分**: ボードを見て `today: true` を3つまで付ける（Claude に「今日やるを提案して」でも可）
- **週1回15分**: Claude に「週次レビューして」と頼む
  - Inbox を空にする
  - `waiting` のものに催促が必要か確認する
  - 期限切れ・放置されたタスクを洗い出す
  - `done` になって1週間以上経ったタスクを `90_Archive/` へ移す
  - 不要になったタスクは `someday` にするかアーカイブする
