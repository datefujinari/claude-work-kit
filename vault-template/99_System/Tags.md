# タグ一覧

タグは階層タグ（`/` 区切り）で管理する。新しいタグを作ったらここに追記する。
フォルダで表せることはタグにしない（例: `#project` は不要。`type` で表す）。

## 領域
- `area/work` 仕事
- `area/learning` 学習
- `area/dev` 開発

## 技術トピック（例・必要に応じて追加）
- `tech/python`
- `tech/javascript`
- `tech/git`
- `tech/ai`

## 状態・用途
- `meta` Vault自体に関するノート
- `todo` 要対応がある
- `idea` アイデア
- `question` 未解決の疑問
