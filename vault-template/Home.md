# Home

このVaultの入口。人間とAI（Claude）の共同ナレッジベース。
運用ルールは [[CLAUDE]] を参照。

## 使い方（人間向けクイックガイド）
- とりあえずメモ・やること → `00_Inbox/`（[[00_Inbox/Inbox|Inbox]] に1行ずつ書くだけでOK。整理はClaudeに「Inbox整理して」と頼む）
- 進捗の報告 → Claudeに「〇〇終わった」「〇〇は△△待ち」と伝える
- 毎朝 → 「今日やるを提案して」／週1回 → 「週次レビューして」
- 今日の記録 → デイリーノート（カレンダーアイコン / コマンド「今日のデイリーノートを開く」）
- 新規ノート → コマンド「テンプレートを挿入」で種類を選ぶ
